## 📌 Projetos em destaque

**[SCPI — Sistema de Chamada de Presença Inteligente](https://github.com/Gustavo-Falci/SCPI)**
API de presença automatizada por reconhecimento facial (AWS Rekognition). Back-end em **FastAPI + PostgreSQL**, app mobile em React Native/Expo. Inclui autenticação segura, rate limiting e conformidade com LGPD.

**[Portal_Suporte — Portal de Chamados](https://github.com/Gustavo-Falci/Portal_Suporte)**
Portal corporativo de tickets em **Django + PostgreSQL** com integração ao **IBM Maximo** via REST e listeners de e-mail. Em produção com Gunicorn + Nginx na Oracle Cloud.

**[Organizador Financeiro (FinançasFácil)](https://github.com/brunoaugusto1510/organizador-financeiro)**
Sistema full-stack de finanças pessoais. API REST em **Node.js + Express + MongoDB** com autenticação **JWT/bcrypt**; frontend com Chart.js e deploy na Vercel. Projeto em equipe.

**[Achados e Perdidos](https://github.com/brunoaugusto1510/achados_e_perdidos)**
Sistema de gestão de achados e perdidos escolar. App **Flutter (Dart)** com back-end serverless em **Firebase** (Firestore + Cloud Functions). Projeto em equipe.
